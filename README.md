# 🌐 Language Translation Tool (Task 1)

A multilingual language translation web application built with Python and Flask. The application allows users to translate text between different languages through a simple and interactive web interface.

## ✨ Features

- Translate text between multiple languages
- Source and target language selection
- Automatic source language detection
- Copy translated text to clipboard
- Text-to-speech functionality
- Clean and user-friendly interface

## 🛠️ Tech Stack

- **Python** – Backend development
- **Flask** – Web framework
- **HTML5, CSS3, JavaScript** – Frontend
- **Translation API** – Language translation
- **Text-to-Speech** – Speech functionality

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/OmkarSolat-17/CodeAlpha_LanguageTranslationTool.git
cd CodeAlpha_LanguageTranslationTool
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the application

```bash
python app.py
```

### 4. Open in browser

Visit:

```text
http://127.0.0.1:5000
```
